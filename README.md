# База ключей для Яндекс Директ

Онлайн-база ключевых фраз (по типу Key Collector): https://sirlondog.github.io/keyword-base/

В этом репозитории только код сайта. Сами данные лежат файлом `data/keywords.json`
в приватном репозитории `sirlondog/keyword-clusters`. Сайт читает и сохраняет его
через GitHub API по личному токену, который хранится только в браузере.

## Возможности

- **Все ключи** — общая база фраз. Каждая фраза лежит не больше чем в одном кластере.
- **Кластеры** — отдельные таблицы («Собрать компьютер», «Купить компьютер» и т. д.).
- **Списки** — отдельные именованные наборы фраз с описанием, для чего они (например, минус-слова).
- **Статус «загружено»** — можно ставить массово, чтобы видеть, какие ключи уже работают в рекламе.
- **Добавление ключей** с отсевом:
  - дублей, в том числе с другим порядком слов, разным регистром, ё/е и операторами `! + " [ ]`;
  - фраз длиннее 7 слов (минус-слова в длину не считаются).
- Поиск, фильтр по статусу, сортировка, выделение с Shift, копирование в буфер, выгрузка в CSV.
- **Массовое «❗ Добавить !»** — ставит `!` перед каждым словом выделенных фраз; слова, где `!` уже есть, и минус-слова не трогает.
- **Группировка слов кластера** — попап со списком отдельных слов и числом фраз, в которых они встречаются; по клику на слово фразы фильтруются, галочками их можно перенести в другой кластер или удалить выбранные слова из фраз.
- Подтверждения удаления и отмены сборов показываются в окне сайта с лёгким затемнением фона — без системного чёрного окна браузера.
- **Частотность Wordstat** через XMLRiver: кнопка «📊 Частотность» (в панели инструментов или для выделенных фраз) запускает сбор в GitHub Actions; три колонки `WS`, `"WS"`, `"!WS"` и сортировка по ним.

## Подключение

1. Создайте [fine-grained токен](https://github.com/settings/personal-access-tokens/new):
   Repository access → Only select repositories → `keyword-clusters`;
   Permissions → Contents → Read and write.
2. Откройте сайт → «Настройки» → вставьте токен.

Если при сохранении появляется **«Not Found»**, значит токен не видит приватный репозиторий
`keyword-clusters` (например, в нём выбран только `keyword-base`). Откройте токен на GitHub
→ **Repository access** → добавьте `sirlondog/keyword-clusters` и сохраните. Создавать новый
токен не обязательно: у fine-grained токена можно изменить список репозиториев.

Изменения сохраняются автоматически через пару секунд, каждое сохранение — отдельный коммит
в `keyword-clusters`, поэтому любую версию базы можно восстановить из истории.

## Группировка слов в кластере

Кнопка «▤ Группировка слов» появляется в заголовке выбранного кластера. В окне:
- слева — отдельные слова и число фраз кластера, в которых они встречаются; формы одного слова (`компьютер` / `компьютера`) объединяются, по клику на слово — фильтр фраз;
- справа — фразы с галочками, поиском и числом-суммой вхождений их слов (подробности — в подсказке при наведении);
- внизу — выбор кластера назначения, кнопки «Переместить» и «Удалить» (удаляет отмеченные фразы из базы).

Та же кнопка «Удалить» для выделенных галочками фраз есть в общей панели над таблицей — она работает во всех разделах (база, кластер, список).

Режим «✖ Слова для удаления»: выберите слева группу слов (например, `спб`), справа отметьте
конкретные слова и нажмите «Удалить слова». Слова убираются только из фраз текущего фильтра.
Фраза, где после удаления не останется слов, и фразы, которые станут дублями existing-записей,
пропускаются. При смене группы или поиска выделение слов сбрасывается.

Например, для фраз `купить компьютер спб`, `заказать компьютер спб`, `доставка компьютера спб`
получится: `спб — 3`, `компьютер — 3`, `купить — 1`, `заказать — 1`, `доставка — 1`.
Минус-слова в подсчёт не попадают.

## Сбор частотности

1. Выделите нужные фразы галочками (или не выделяйте — тогда берутся все фразы раздела с учётом поиска и фильтра).
2. Нажмите «📊 Частотность», выберите виды частотности и регион, посмотрите оценку запросов и стоимости.
3. «Запустить сбор» — сайт пишет задание в `data/wordstat-job.json`, его подхватывает GitHub Actions.
   Ключ XMLRiver лежит в секретах приватного репозитория и **не попадает в браузер**.

Во время сбора база доступна только для чтения; сверху показывается прогресс и кнопка «Остановить».
Можно закрыть страницу — сбор продолжится на стороне GitHub. Частотность появляется в таблице
по мере записи пачек; в CSV и подсказках к колонкам видны регион и дата сбора.

Виды частотности:
- `WS` — базовая, запрос без кавычек;
- `"WS"` — фразовая, запрос в кавычках;
- `"!WS"` — точная, `"!слово !слово"`; по умолчанию выключена, так как стоит дороже и выдаёт меньше.

Тариф XMLRiver — ориентировочно 25 ₽ за 1000 запросов (0,025 ₽ за запрос); оценка в окне сбора
учитывает только фразы, у которых ещё нет частотности за выбранный регион. Повторные запросы
при ошибках 101/110/115/500 идут с задержкой; запросы с кодами 2/400 пропускаются.
