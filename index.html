Подключение к GitHub

База хранится файлом JSON в вашем репозитории. Нужен токен: создать fine-grained токен → Repository access: Only select repositories → нужный репозиторий → Permissions → Contents: Read and write. Токен хранится только в этом браузере.

Если сохранение падает с «Not Found» — значит, токен не видит репозиторий keyword-clusters: откройте созданный токен на GitHub и добавьте этот репозиторий в Repository access. Можно редактировать существующий токен, создавать новый не обязательно.
